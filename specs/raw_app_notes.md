Two versions of the app: Admin version - Requires special logins and has all the normal features and functions of the normal version of the app plus additional features. Able to create users, including their username and password for them to be able to login to the normal version of the app. Able to promote users to admin level for them to be able to access this version of the app. Able to remove users so that they can no longer have access to the normal version of the app. Able to see credits usage of each user that uses the app. Able to remove consolidated files and business names - Recovery option that lasts 30 days Able to receive requests via email from users regarding the deletion of consolidated files. Able to edit the database which contains the desired format for the ledger mapping and the Ledger database of the analysis accounts the app will use for the ledger mapping Normal version - login page where the user needs to put in a username and password User can upload either pdf, CSV or Excel and carry out the either one of the two functions depending on the type of file uploaded. 2 Functions: 1. Email function - pdf/CSV/Excel - Create a business name folder or have the option to select from business name folders already saved to the app. The user will upload multiple pdfs/CSVs/Excels of bank statements/credit card statements. Based on the unique key which is the bank account number/credit card number, check if the user has uploaded statements from the same bank account/credit card or different bank accounts/credit cards. If they are from the same bank account/credit card, check for duplicates and remove them, ask the user for accounting period, check for missing periods and display missing periods of the bank account/credit card. If they are from different bank accounts/credit cards, check for duplicates and remove them, ask user for accounting period, check for missing periods and display the missing periods for each bank account/credit card. Then, for one bank account/credit card, draft an email with the phrase “[Company name] - missing period” (as the word not the dates themselves) as the subject line, then in the main email, have the company name in the address, the accounting period the user chose to look at as dates, the account/credit card number and say that there have been missing periods identified and list the missing periods as the dates themselves. For multiple bank accounts/credit cards, draft an email with the “[Company name] - missing period” (as the word not the dates themselves) as the subject line, then in the main email, have the company name in the address, accounting period the user chose to look at as dates, the account/credit numbers and say there have been missing periods identified in these bank statements/credit card statements and list the missing periods for each bank account/credit card as the dates themselves under the corresponding account/credit card number. For both emails, keep the tone formal and to the point, without unnecessary jargon. Then in both cases, ask the user if they want the files to be consolidated in the date order. If yes, for one bank account/credit card, save the information about the missing periods and save the consolidated file under folders with the accounting periods dates as the title which are within the business name folders so that when the user chooses to, they can send the missing information to the app and rerun the consolidated file to include this information. For multiple bank accounts/credit cards, save the information about the missing periods and save the consolidated files for each bank account/credit card under folders with the accounting periods dates as the tiles which are within the business name folders so that when the user chooses to, they can send the missing information to the app and rerun the consolidated files to include this information. In the section with the business name folders and the folders of accounting periods, which contain the consolidated files, there should be the options to either download the consolidated files from the app, rerun the consolidated files through the same process as before with the new bank statements/credit card statement the user uploads or send a request via an email to the admins for the file to be deleted if the user wants to start over. If no, just save the information about the missing periods under the folders with the accounting periods dates as the title which are within the business name folders. 2. Ledger mapping - CSV/Excel - Create a business name folder or have the option to select from business name folders already saved to the app. The user uploads CSVs/Excels for the same bank account/credit card statements. They cannot upload bank statements/credit card statements from different bank accounts/credit cards. Checks duplicates and removes them. Ask the user for the accounting period and the opening balance. Consolidate the files in chronological order and if there is a balance column, calculate balances based on the opening balance and show any discrepancies between the calculated balances column and the balance column in the consolidated file. If there is no balance column in the consolidated file, calculate the balance and display it in the consolidated file. Save this file under folders with the accounting periods dates as the title which are within the business name folders. Then ask user if they are ready for accounts categorisation and ask which path they want to go with, bank path or invoice path. If they say yes, using the database within the app which contains the final desired format of the two VT files required as the output and the Ledger database, create the two CSV files from the consolidated file for the payments/Money Out and receipts/Money In in the desired format based on the desired format from the database. PAY is for Money Out and REC is for Money In. Then for analysis account, use the database to fill out the analysis column based on the path the user chose between bank path and invoice path to decide which Analysis account column of the database the app will use to fill the analysis account column of the final files. Save these files under the accounting period folder of the business name folder. These two files should have the options to be downloaded from the app or requested to be deleted by sending an automatic email to the admins like before. If they say no, don’t carry out this step and instead, just make sure the consolidated file is saved in the correct folder of the app. Overall, the app should have a few main pages. Login page - user logs into the app using a username and password. Home page - The user has the ability to choose which function from the ones above to carry out and when they choose which one, it should give them the ability to upload the files and begin the process. Admin page (admin only access) - This is the page where the admin is able to carry out all the abilities that were listed above Folders page - The page where the Business name folders are saved and within them, the accounting period folders which contain the consolidated files and missing period’s information.
